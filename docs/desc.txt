分布式消息总线

背景：
面向以 PHP 为主、无常驻内存的业务线，统一收口 RocketMQ 对接的分布式消息总线：以中台模式提供易用 SDK、中心统一消费回调与 BinLog 变更订阅，避免 40+ 业务项目重复造轮子对接消息队列。

提供能力：
生产 SDK 与中心消费回调：封装易用 SDK 供生产端接入，屏蔽与 RocketMQ 对接的复杂度并统一消息格式；消费端采用「中心统一消费 + 按配置回调各服务」模式，解决 PHP 无常驻内存、难以直接消费 MQ 的问题，业务方无需维护消费者即可获得消息推送。
BinLog 变更订阅：基于 Canal 监听 MySQL binlog，按配置中心规则将数据变更回调到对应业务，实现数据变更的准实时分发与业务解耦。
配置中心热插拔：监听、暂停消息、回调路由等均由配置中心动态下发，无需发版即可灵活创建监听与暂停消息，提升运维与接入灵活性。
